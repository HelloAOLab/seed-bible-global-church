# Feature map — current repo to the new app

Coverage means the new stack must do the thing. `packages/seed-bible` stays on CasualOS at seedbible.org until the row works on the triad.

Columns:

- **Today** — where it lives in this repository now
- **New app** — reader-web / reader-a2a / reader-mcp / Home / town / serving plane
- **Agent** — whose skill: person, org, workspace, or svc
- **Ontology** — `seed:` class or upper term
