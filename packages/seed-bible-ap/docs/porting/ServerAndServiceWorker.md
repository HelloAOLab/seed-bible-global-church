# Porting `server/` (SSR) and `standalone/sw.ts` (the service worker)

Source (read-only): `server/index.ts` (Express + SSR worker threads), `standalone/entry-ssr.tsx`,
`standalone/sw.ts` + `swRouting.ts` (Workbox).

| It did                                                                     | Now                                                                                                                                                                                                                                                                                                                                                                   |
| -------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| rendered the whole app on a Node/Bun server with the API snapshot injected | `apps/reader-web/worker/index.ts` — a Worker in front of the assets renders `/read/<t>/<book>/<ch>` on the edge: `src/entry-server.tsx` draws the header and chapter column with the same `renderChapterContent`, sets title, description and `lang`, and injects the API snapshot (`window.__SB_SEED__`) the client's `FreeUseBibleAPI` reuses (`seedResponseCache`) |
| `index.html` placeholders (`<!--APP_HTML-->` …)                            | plain string injection into the built `index.html` (`injectIntoIndex`)                                                                                                                                                                                                                                                                                                |
| hydration of per-reader state on the server                                | **not done**: the client renders over the shell (no `hydrate`); marks, tabs and sign-in are client-only                                                                                                                                                                                                                                                               |
| Workbox precache of the shell, runtime caches for translations and fonts   | `vite-plugin-pwa` (generateSW): shell precached, `bible.helloao.org/api/*` stale-while-revalidate, fonts cache-first, locale chunks on demand; `manifest.webmanifest` + the old icons                                                                                                                                                                                 |
| sitemap, shared pages, customization and playlist SSR                      | later (step 9 cutover, steps 5 and 7)                                                                                                                                                                                                                                                                                                                                 |

Rules kept: the Worker calls only the Bible API; nothing of the reader's is on the server (the seed is public
Scripture); no key.
